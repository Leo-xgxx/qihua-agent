# 提示词优化版（对原萃取任务书的重写）

原版在 `docs/reference/提示词-转写.md`，优化版全文在 [提示词-v2.md](提示词-v2.md)，可直接用于对历史文档（含后续新一季文档）重跑萃取。

优化点全部来自**实际把萃取产物落库运行时暴露的问题**，不是纸面推演：

| # | 原版的问题（实践中暴露） | v2 的改法 |
|---|---|---|
| 1 | 萃取物不分类，全部进一张"方法论主表" | 按四类分拣：分析方法 / 判断规则 / 指标口径 / 结构化事实——四类落库去向不同（分别进任务清单、规则卡、口径手册、数据快照），混在一起无法落地 |
| 2 | 「原文未标注」只要求标注，不收口 | 新增交付物《待拍板清单》：阈值缺失/口径缺失/假设未验证三类分列，直接作为评审会议程（实践：口径10条草案全是待拍板项） |
| 3 | 对标方法只要求"引入"，无绑定约束 | 硬约束三项绑定：诊断缺口编号+使用场景（哪步用/输入/样本量/产出什么决策）+启用前置条件；缺一不得入表（防方法货架） |
| 4 | 无转引规则 | 引用不在手头的文档必须标「转引」（实践：《裤子27春企划pdf.pdf》原件缺失，相关页码全是转引） |
| 5 | 无口径冲突处理 | 新增《口径冲突表》（实践实锤：同一份额数据两季金额单位一份用元、一份用万元） |
| 6 | 无字段漂移处理 | 同一模板字段跨季漂移须记录映射（实践实锤：老品复盘卡维度名各季不同） |
| 7 | 表格数据只转述不抽取 | 新增交付物《结构化数据表》：表格优先抽成 CSV 长表、逐行带文档+页码溯源（实践：份额43行+复盘卡217行已验证可行） |
| 8 | 无验收方式，萃取质量不可检查 | 新增第七节：溯源抽查100%命中、未标注完备性抽检、冲突零遗漏、对标绑定逐行查 |
| 9 | 一次性任务，新文档来了要重做 | 新增第五重成果属性「可增量」：按同一规则增量萃取合并，产物有明确入库去向 |
| 10 | 背景与五大痛点叙事写在 prompt 里 | 叙事是给人对齐的立项故事，对模型是弱信号且易引偏；压缩为「任务目的」两条功能句——三类输出定取舍、双使用者定质量标准。痛点 2/3 已翻译成硬规则（口径冲突表/待拍板清单/样本量红线），规则在场叙事即冗余。给人的完整背景保留在 reference 原版中 |
| 11 | 成果属性是四个形容词（可沉淀/可复制/可落地/可标准化） | 形容词改变不了模型行为，逐条翻译成可检查形式（入库去向/抽卡实测/机器可校验/五要素齐全），并与第七节验收对齐 |
