# 萃取任务书重写版（说明）

原版提示词在 `docs/reference/提示词-转写.md`。本目录是**推倒重写**的版本：[萃取任务书-重写版.md](萃取任务书-重写版.md)，不是对原版的修补。

## 为什么重写而不是修补

原版把萃取定义成"写一份报告"。报告的结构、粒度、列名由模型现场发挥——**喂不同资料、甚至同资料跑两次，产出结构都会漂移，无法比对、无法合并、无法入库**。重写版把任务重新定义为"按固定 schema 抽取记录"：结构不再由模型决定，由任务书决定。

四件套保证格式稳定：
1. **记录 schema**：四类记录（方法/规则/口径/事实）逐字段定义，字段顺序固定、空值写法固定；
2. **固定词表**：所有分类字段只许用枚举值，自创值=违规；
3. **判定规则**：粒度、跨文档合并、冲突、图片页、转引、字段漂移——每个需要裁量的地方都给了判据；
4. **自检闸**：六条机器式检查，任一不过不得交付。

诚实边界：提示词能钉死的是**结构**；字段内的文字表述仍会每次微差。要彻底钉死格式，产出后应再跑一个机器校验器（与本仓库 `scripts/check_brief.py` 同款思路），待有真实产出后按 schema 补一个即可。

## 原版问题 → 重写版解法

| # | 原版的问题 | 重写版的解法 |
|---|---|---|
| 0 | 报告式交付，结构靠模型发挥，每次漂移 | 任务改为记录抽取：schema+词表+固定产出文件清单（§2/3/4） |
| 1 | 萃取物不分类 | 四类记录各自 schema，对应资产库四个去向 |
| 2 | 「原文未标注」只标不收口 | 待拍板条目 P-### 成为固定产出，空值写法词表化 |
| 3 | 对标方法无绑定约束 | 五项绑定 schema，诊断 ID 必须真实存在（自检第5条） |
| 4 | 无转引规则 | §6.5 强制转引前缀 |
| 5 | 无口径冲突处理 | 口径记录逐版本并列+冲突字段，自检第4条查零遗漏 |
| 6 | 无字段漂移处理 | §6.6 并集+漂移映射入备注 |
| 7 | 表格只转述不抽取 | 04-数据表 CSV 强制，文件名与末三列固定，原文不清洗 |
| 8 | 无验收方式 | §8 六条自检，任一不过不交付 |
| 9 | 一次性任务 | §7 增量模式：ID 稳定，只交付新增与变更 |
| 10 | 背景痛点叙事写进 prompt | 全文只有纪律/规格/任务定义；目的压成取舍标准 |
| 11 | 成果属性是形容词 | 属性全部变成 schema 字段与自检条款（完整性/五要素/抽查） |
