* 溯源：《26休闲裤夏季企划案.pdf》第5、12-15、35-39页；《裤子27春企划pdf.pdf》第7、25页；《26秋冬休闲裤企划案.pptx》第8张幻灯片。

**Top 3：用户调研与评论原声（问卷评分、意向测试、差评聚类、购买原因挖掘）**

* 核心优势：唯一回答「为什么」的数据源；直接产出过立项决策（工装裤81%意向→立项，26秋冬s40；直筒版37%需求→立项，26夏p29）。

* 适用场景：功能需求排序（27春p22）、面料双维评分（27春p22）、新品立项第三重依据（26秋冬s39-43）。

* 复用价值：高，但当前为最大短板环节（见下）。样本量、抽样框、问卷工具均需标准化后才能成为可信资产。

* 溯源：《26休闲裤夏季企划案.pdf》第29、31页；《裤子27春企划pdf.pdf》第22、25、33页；《26秋冬休闲裤企划案.pptx》第23、32、40张幻灯片；《！27夏品类企划案-休闲裤.pptx》第15-16、20张幻灯片；《26春休闲裤企划.pptx》第13张幻灯片。

### ② 需求抽样与验证环节的普遍短板与落地改进建议

**普遍短板（均有原文证据）：**

1. 样本量小且不稳定：N=82（26夏p29）、N=135（27春p22），多个调研样本量原文未标注。
2. 抽样框偏倚：只调已购用户，流失用户与未购用户系统性缺失（26夏p29注明「未对隐腾流失用户调研」）。
3. 数据来源非标准化：用评论汇总代替调研（26春s13，N=377/287为用户评论汇总），无法保证样本结构。
4. 验证闭环缺失：调研结论→立项之间缺「小批量验证」闸门时就会翻车——运动腰头「未验证充分机会下布局2款产品」被评审否决（27春p46）；7号B型「5000件无法验证各渠道销售效率」（27春p24）。
5. 效果评估无实验设计：页面改动无法排除爆款视频干扰（26夏p31）。

**落地改进建议：**

* **样本量红线**：①占比类结论（如「37%要直筒」）样本量≥200，且置信区间随结论一并呈现；②评分对比类（需求分vs感受分）≥300；③立项闸门类（意向购买比例）≥300且含未购人群配额≥30%；④N<100 的调研结论在企划案中只能作为「线索」标注，不得作为立项依据。

* **必调人群（四类配额）**：①本品已购用户（验证产品短板）；②本品流失/退货用户（验证流失根因，当前系统性缺失）；③竞品已购用户（验证竞品真实优势，对标简木/霞湖世家/九牧王）；④目标价格带未购人群（验证高价格带与新品类机会，支撑PRO系列与天猫扩张）。

* **验证闭环机制**：调研结论→意向闸门（≥300样本）→先锋计划小批量（参考7号B型5000件模式）→中期复盘（销售效率+顾客反馈双维）→扩量验证（20000件级）→换代/转正规决策；任何一级未通过不得跳级。评审会否决意见（27春p46）必须进入下季「看复盘」章节，闭环跟踪。
