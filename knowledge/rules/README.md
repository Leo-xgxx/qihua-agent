# 规则卡

「来源」字段枚举（只许三值，check_brief 机器校验）：**评审拍板 / 预测验证 / 历史萃取·待确认**。
- 评审拍板：出自评审会记录（含否决与质询）；
- 预测验证：预测台账判定「达成」后沉淀；
- 历史萃取·待确认：仅限冷启动种子卡（R-202608-1~9，覆盖全部9个★级核心方法）。首次评审会逐张裁决：转正（来源改为评审拍板）或删。此例外仅此一次。

每季新增 ≤10 张，失效即删（git 留历史）。命名 `R-YYYYMM-n.md`，模板见 `templates/rule-card.md`；frontmatter 的 id 必须与文件名一致、失效条件必填（机器校验）。
agent 答题前必须全量读本目录。
