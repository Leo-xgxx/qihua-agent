# 可选方法登记（行业对标增补，按需启用）

来源：萃取报告交付物4（docs/reference/）。原则：**用到才启用、启用才进十问正文**，不做方法货架。
每条 = 挂在哪问 / 解决什么 / 启用条件。

| 方法 | 挂在哪问 | 解决什么（对应报告诊断） | 启用条件 |
|---|---|---|---|
| KANO 需求分类 | Q8 | 功能需求只有均值排序，必备/期望/兴奋属性不分（「透气9.2」与「防晒7.91」被同等对待） | 新品定义阶段问卷，正反向问句，N≥300 |
| PSM 价格敏感度测试 | Q10 定价字段 | 价格带决策只看份额，提价无用户接受度证据 | 进攻价格带/新品类定价；**前提：定价决策归企划（待确认）** |
| 联合分析（Conjoint） | Q9/Q10 | 版型×腰头×面料×价格组合偏好靠讨论决策（评审质询先例） | 组合类立项问题；问卷设计+样本量达标 |
| JTBD 场景任务访谈 | Q7/Q8 | 需求按功能收集、缺场景链条（评审要求"购买决策点+穿着整体链条"） | 深访 8–12 人/主题，输出场景链条图 |
| A/B 分流实验规范 | 页面/素材/价格改动归因 | 「爆款视频影响无法去除」→效果归因不成立 | 有分流能力（直播间/货架分桶）；改动登记制 |
| 退货原因编码 + Cohort 追踪 | Q7 输入升级 | 退货率无阈值、原因靠零散调研 | 订单级退货原因数据接入后，按上市批次追踪 |
| AAR 复盘五段式 | Q1 | 同一教训跨季重复（隐腾上市过早）；**本系统已内建**：Q1+预测台账 = 预期-实际-差异-根因-规则 | 已启用 |
| 竞品月度监测 | Q4/Q5 输入升级 | 竞品分析随取随变、口径不稳 | 路线第二步（竞品打标产线）跑顺后，从每季一次升级为月度档案 |
